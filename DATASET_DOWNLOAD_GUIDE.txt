================================================================================

**Dataset Name**: Intrusion Detection Evaluation Dataset (CIC-IDS2017)
**Size**: ~50GB total (11.8 million network flows, 85 features)

**Format**: CSV (machine learning ready) or PCAP (raw)

   - GeneratedLabelledFlows.zip (Alternative)
   - PCAP files (Raw network traffic)
   
   Steps:

   2. Click "MachineLearningCSV.zip" (download CSV files)

   4. CSV files ready to use

B) Kaggle Mirror (Alternative if URL above is slow)
   URL: https://www.kaggle.com/datasets/chethuhn/network-intrusion-dataset
   
   Steps:
   1. Create free Kaggle account
   2. Download dataset
   3. Extract to: c:\myprojects\Kaisen\datasets\CICIDS2017\

DATASET CONTENTS:

**Day-by-day breakdown:**
- Monday (Normal Traffic): 11.0 GB - benign activity only
- Tuesday (FTP/SSH Brute Force): 11 GB - brute force attacks
- Wednesday (DoS/DDoS): 13 GB - denial of service attacks
- Thursday (Web Attacks): 7.8 GB - SQL injection, XSS, etc.
- Friday (Botnet/Port Scans): 8.3 GB - malware and reconnaissance

**Attack Types Included:**
✓ Brute Force (FTP, SSH)
✓ DoS (Slowloris, Hulk, GoldenEye)
✓ DDoS (LOIT - Low Orbit Ion Cannon)
✓ Web Attacks (SQL injection, XSS)
✓ Infiltration (Lateral movement, backdoor)
✓ Botnet (ARES malware)
✓ Heartbleed (SSL vulnerability)

**Features Included:**
- 80+ network flow features
- Source/Destination IP, Port, Protocol
- Flow duration, packet counts, byte counts
- Flag statistics (SYN, ACK, FIN, RST, PSH, URG)
- Average/Min/Max packet sizes
- Inter-arrival times
- Label (Normal or specific attack type)

**CSV SCHEMA** (Important for mapping to our 13-feature OS-layer):
┌─ Source IP
├─ Destination IP
├─ Source Port
├─ Destination Port
├─ Protocol
├─ Flow Duration
├─ Total Forward Packets
├─ Total Backward Packets
├─ Total Payload Forward
├─ Total Payload Backward
├─ Forward Packet Size Average
├─ Backward Packet Size Average
├─ [70+ more features]
└─ Label (Normal or Attack)

MAPPING TO KAISEN'S 13-FEATURE OS-LAYER:
┌─ cpu_usage → derived from packet rate / time
├─ memory_usage → derived from flow complexity score
├─ process_count → mapped from port diversity
├─ network_connections → total forward + backward packets
├─ unique_ips → count of unique destination IPs
├─ failed_logins → detected in SSH attempts on port 22
├─ lateral_movement → port scan patterns (90+ ports)
├─ port_scan_score → scanning behavior detection
├─ resource_exhaustion → flow duration + packet rate
├─ entropy_spike → packet size variance
├─ connection_rate → packets per second
├─ anomaly_score → aggregate statistical deviation
└─ previous_anomaly_score → temporal correlation

TROUBLESHOOTING
================================================================================

Q: Download URL is slow or down?
A: Use Kaggle mirror: https://www.kaggle.com/datasets/chethuhn/network-intrusion-dataset

Q: AWS S3 command not working?
A: Install AWS CLI first: pip install awscli
   Then: aws s3 sync --no-sign-request --region us-east-1 "s3://cse-cic-ids2018/" dest

Q: CSV files are huge (13 GB per day)?
A: Load in chunks:
   df = pd.read_csv("file.csv", chunksize=100000)
   for chunk in df:
       process(chunk)

Q: Feature mapping unclear?
A: See MAPPING TO KAISEN'S 13-FEATURE OS-LAYER section above
   Extract statistical features from network flows to approximate OS metrics

Q: Labels are string ("BENIGN", "FTP-Patator")?
A: Convert to binary:
   y = (data['Label'] != 'BENIGN').astype(int)
   1 = attack, 0 = benign
