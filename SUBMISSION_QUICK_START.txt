   If real dataset evaluation is required, see Limitations section.

A: Yes! Run: cd ResearchDocs/docs && pdflatex paper.tex
   You should get paper.pdf in seconds (all figures are PDFs).

   to run additional scenarios, dataset sizes, or baseline comparisons.

   For journals, check their policies (most require exclusivity).

A: Paper is already anonymized. When uploading to conferences,
   use anonymous handles. Don't include personal information
   in supplementary materials.
