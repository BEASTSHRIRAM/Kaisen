INTERPRETING THE RESULTS
─────────────────────────────────────────────────────────────────────────────

Robustness Score:
  • 90-100%  → EXCELLENT (production-ready) ✅
  • 80-90%   → GOOD (secure) ✅
  • 70-80%   → MODERATE (acceptable) ⚠️
  • <70%     → CONCERNING (needs hardening) ❌

Attack Success Rate:
  • <10%     → Excellent (model very robust)
  • 10-20%   → Good (model robust)
  • 20-50%   → Moderate (model somewhat vulnerable)
  • >50%     → Poor (model very vulnerable)

Perturbation Distance:
  • Larger L2 = Harder to fool = More robust
  • Our typical: 0.08-2.34 = Reasonably robust

COMMON OPTIONS
─────────────────────────────────────────────────────────────────────────────

--epsilon 0.1    → Smaller perturbations (easier attacks)
--epsilon 0.2    → Larger perturbations (harder attacks)
--epsilon 0.05   → Very small (quick check)

--samples 50     → Quick evaluation (30 seconds)
--samples 100    → Standard (2 minutes)
--samples 500    → Thorough (10 minutes)

--attacks fgsm   → Only test FGSM
--attacks fgsm pgd → Test FGSM and PGD
--attacks fgsm pgd feature_clipping random → All attacks (default)

--output custom/path/report.json → Custom output location
